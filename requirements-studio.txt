# Khmer AI Content Studio — backend requirements.
#
# Deliberately small: the studio only needs a web stack plus numpy/PIL for its
# fallback renderers. The heavy models (Ollama, ComfyUI/Wan, MMAudio, RVC,
# sherpa-onnx) run as *separate local services*, so they are NOT pip deps —
# see README-STUDIO.md for installing each one.
#
#   python -m pip install -r requirements-studio.txt
#
# If you also want the legacy `ai_creator/` studio in the same venv, install
# requirements.txt as well (the two share only `ai_creator.ollama_client`
# and `ai_creator.voice`, both of which import lazily).
